## Consideraciones de Diseño

### Para la página /demos
- **Showcase visual** — cada demo debe verse como un producto real, no un placeholder
- **Cards con screenshots** — mostrar cada demo como si fuera un producto
- **Links a demos live** — cada card debe tener un botón "View Demo" que abra el demo estático
- **Hover effects** — cuando pasas el mouse, se ve más info del demo
- **Mobile-first** — todo debe verse perfecto en mobile

### Para los demos individuales
- Cada demo es una **página estática individual**
- Se pueden guardar como:
  - `demos/restaurant/`
  - `demos/salon/`
  - `demos/contractor/`
  - etc.
- Cada demo tiene su propio `index.html`
- Usan el mismo CSS base pero con estilos temáticos
